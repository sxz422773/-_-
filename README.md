# 书间 · 网络小说书源书库

免费前端：https://sxz422773.github.io/-_-/

网页由 GitHub Pages 托管。数据库、收藏、资料采集、书源检测、查询和小说下载全部在用户本机处理，不上传到此仓库。

## 启用 Pages

仓库 Settings → Pages → Build and deployment → Source 选择 Deploy from a branch，Branch 选择 main，目录选择 / (root)，点击 Save。

## 使用

网页外观无需本地服务器即可打开。需要查询或下载时，在自己的电脑启动更新后的“打开书间”，再在网页顶部点击“连接本机服务”。浏览器询问访问本地网络时允许。

本机后台地址固定为 http://127.0.0.1:8765 。未启动时页面会提示尚未连接，不会假装有书库数据。手机上的 127.0.0.1 指手机自己，并非电脑。

本机后端只监听回环地址；跨域仅放行 https://sxz422773.github.io，写入操作继续校验临时令牌。仓库无数据库、书源、密钥或下载文件。
